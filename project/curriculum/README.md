# Curriculum outlines

The JSON files contain original, unreviewed planning outlines, six lesson ideas per module for each direction. They are not lessons, recordings, validated CEFR mappings or proof of A1 attainment. Titles, objectives, sequencing, examples, script coverage and grammar must be checked by qualified Russian and Uzbek educators, adjusted against the outcome matrix and piloted with absolute beginners. Source rights, language quality, accessibility and assessment evidence remain release gates.

The two tracks are independently outlined for different learner needs; translations were not simply reversed. These outlines are private editorial planning material and are not automatically published. Existing demonstration lessons remain prototypes. The product plan remains authoritative for the full intended scope and launch criteria.
